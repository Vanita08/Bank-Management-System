# 🏦 Bank Management System (C++)

## 📌 Project Overview
The Bank Management System is a C++ mini project developed using Object-Oriented Programming (OOP) concepts. It is designed to manage basic banking operations such as creating accounts, depositing money, withdrawing money, checking account balances and displaying customer account details.

This project demonstrates how C++ programming and OOP concepts can be used to develop a simple real-world banking application.

## ✨ Features
- Create a new bank account.
- Deposit money into an account.
- Withdraw money from an account.
- Check account balance.
- Search for an account using account number.
- Display all available accounts.
- Prevent duplicate account numbers.
- Validate deposit and withdrawal amounts.

## 🛠️ Technologies Used
- **Programming Language:** C++
- **Concepts:** Object-Oriented Programming
- **Compiler:** GCC (G++)
- **Code Editor:** Visual Studio Code

## 📚 OOP Concepts Used
1. **Classes and Objects:** Organize banking information and operations.
2. **Encapsulation:** Manage data using access specifiers.
3. **Inheritance:** SavingsAccount inherits from BankAccount.
4. **Polymorphism:** Function overriding using the display() function.
5. **Abstraction:** Organize banking operations into classes and functions.
6. **Constructor:** Initialize account details.

## ▶️ How to Run the Project

**Step 1:** Download or clone this repository.

**Step 2:** Open the project folder in Visual Studio Code.

**Step 3:** Open the terminal and compile the code:

```bash
g++ BankManagement.cpp -o BankManagement
```

**Step 4:** Run the program.

For Windows:

```bash
BankManagement.exe
```
